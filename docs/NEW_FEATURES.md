# 追加機能ガイド

このドキュメントは、今回追加した3つの主要機能と、関連する設定の使い方をまとめたものです。

## 1. 治療内容連動型 LINE自動フォローアップ＆リコール

予約を「完了」にすると、メニューに応じてLINE（未連携の場合はメール）で自動的にフォローします。**スタッフの追加操作は不要**です。

- **設定場所**: 管理画面 → 設定 → フォローアップ
- **仕組み**:
  - 予約のステータスが `completed` になった瞬間に、メニューに紐づくテンプレートから送信予約を作成します（`server/followup.ts`）。
  - スケジューラ（`server/scheduler.ts`）が毎分キューを確認し、送信時刻が来たメッセージを送ります。
  - LINE連携(`lineUserId`)があればLINE、なければ患者のメールに自動フォールバックします。
- **テンプレート種別**:
  - 外科・抜歯系: 翌日の指定時刻に容体確認メッセージ
  - 検診・クリーニング系: お礼＋数ヶ月後にリコール
- **文面変数**: `{patientName}` `{clinicName}` が使えます。

## 2. スマート口コミ誘導＆不満吸収

- **設定場所**: 管理画面 → 設定 → 口コミ誘導
- **患者用URL**: `/review/<医院slug>`（QRコードやLINEに設置）
- **動作**: 星評価で閾値以上ならGoogle口コミへ誘導、未満なら同一画面で匿名フォームを展開。匿名意見は院長へ通知され、設定画面の受信箱に表示されます。

## 3. 自費診療デジタルカウンセリング＆電子同意書

- **プラン登録**: 管理画面 → 設定 → 自費プラン（比較表のカードを登録）
- **カウンセリング開始**: 患者一覧の各行の「カウンセリング開始」ボタン
- **流れ**: フルスクリーン比較表 → 「このプランで決定」→ 電子同意書（氏名・日付・治療・金額・免責を自動挿入）→ タブレットで署名 → PDF生成・保存
- **閲覧**: カルテ（受付メモ）画面の患者パネルから、保存済み同意書PDFをいつでも開けます。

### 電子同意書PDFの保存先（Supabase Storage）

PDFは Supabase Storage の非公開バケット `consent-forms` に保存し、閲覧時に署名付きURLを発行します。
本番で有効にするには、以下の環境変数を設定してください（未設定でもDB保存で動作します）。

```
SUPABASE_URL=https://xxxx.supabase.co
SUPABASE_SERVICE_ROLE_KEY=<service_role キー>
```

- キーは Supabase ダッシュボード → Project Settings → API から取得します。
- `service_role` は強い権限を持つため秘匿し、フロントエンドには絶対に露出しないでください。
- バケットはマイグレーションで作成済みです（非公開）。

## 関連する設定の有効化（これまで保存のみで未動作だった項目）

- **患者確認機能 / 確認期限切れ自動キャンセル**: 一般設定の「患者確認機能を有効にする」をONにすると、患者はマイページで「来院を確認する」が押せます。`確認期限（時間前）`を過ぎても未確認の予約は自動キャンセルされ、管理者に通知されます。
- **QRチェックイン**: 一般設定の「QRチェックインを有効にする」をONにして保存すると、設定画面に受付用QRが表示されます。受付に掲示し、患者がスマホで読み取って電話番号を入力すると、本日の予約が「来院済(arrived)」になります（`/checkin/<医院slug>`）。
