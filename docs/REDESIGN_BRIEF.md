# 全面リデザイン・ブリーフ（最強の歯科クリニックSaaSへ）

目的：機能はそのまま、**レイアウト・情報設計・コンポーネントの作りから再設計**し、
「どの大手SaaSよりも使いやすく、売れる」プロダクトにする。これは"磨き"ではなく"作り替え"。

## 絶対に守る制約
1. **色は変えない。** hue/saturation/lightness のトークン値（例 `--primary: 35 23% 70%`）、
   hsl/rgb/hex、Tailwind カラーファミリー（`bg-blue-500` 等）を新規追加・変更しない。
   既にそのファイルで使われている色クラス/トークンのみ再利用する。
2. **機能・ロジックは不変。** props・query key・mutation・イベントハンドラ・状態・
   バリデーション・**`data-testid`** は削除も改名もしない。JSX構造とクラスは大胆に作り替えてよい。
3. **ビルドを通す。** 変更後 `npm run build` が成功すること。

## デザイン原則（best-in-class SaaS）
- **大胆な余白とリズム**：詰め込みすぎない。情報に呼吸を。セクション間 `gap-6`〜`gap-8`。
- **明確な階層**：1画面に主役は1つ。主要指標・主要アクションが一目で分かる。
- **カードベース＋一貫したエレベーション**：`rounded-xl`/`rounded-2xl`、`border border-card-border`、
  必要に応じ `.elevation-card`。影は黒/透明のみ（色は足さない）。
- **データ可視化**：数値は `text-3xl md:text-4xl font-bold tabular-nums`、補助は `text-muted-foreground`。
  進捗・割合はバー/リングで視覚化（既存色のみ）。
- **モーション**：`transition-*`、`active:scale-[0.98]`、hover で `shadow` がふっと上がる程度。派手にしない。
- **モバイル・ファースト**：親指で押せる（主要 `h-12`+）。狭幅で崩れない。表は `overflow-x-auto`。
- **空状態・ローディング**：空はアイコン＋一言＋主要アクション導線。ローディングは実形状スケルトン。

## レイアウトの作り替え方針（画面共通の型）
- **ページヘッダー**：タイトル `text-xl md:text-2xl font-bold tracking-tight` ＋ サブ説明 ＋
  右側に主要アクション（新規作成等）。`border-b border-border bg-background`、必要なら sticky。
- **コンテンツ**：12カラム的な発想で、主役エリア＋サイド情報の2カラム（PC）→ 縦積み（モバイル）。
- **リスト/テーブル**：行は呼吸を持たせ、主テキスト＋メタ＋右にアクション。ステータスはピル。
- **ダイアログ/モーダル**：見出し→グループ化された入力（ラベル `text-sm mb-1.5`）→ 下部に主アクション。

## トーン
落ち着いた上質さ。医療の信頼感＋現代的なテック感。装飾過多にしない。余白と整列で「高い」と感じさせる。
